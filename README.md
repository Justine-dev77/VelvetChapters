# VelvetChapters v3

Cette version permet :
- de créer un chapitre ;
- de choisir son numéro ;
- de modifier un chapitre local existant ;
- de corriger un ancien chapitre affiché comme "Chapitre 100" ;
- de supprimer un chapitre local ;
- de lire les chapitres depuis le sommaire ;
- d'exporter les chapitres locaux en JSON.

## Pour corriger l'ancien "Chapitre 100"
1. Ouvre `editor.html` avec Live Server.
2. Descends dans **Mes chapitres locaux**.
3. Clique sur **Modifier** sur le chapitre 100.
4. Remplace son numéro par `3` (ou celui que tu veux).
5. Corrige éventuellement le titre.
6. Clique sur **Enregistrer les modifications**.

Le chapitre garde son identifiant technique en arrière-plan, mais le site affichera désormais le numéro choisi.
